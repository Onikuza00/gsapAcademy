11. Tambor 3D (Vertical)

Efecto de carrusel cilíndrico de alta gama. Las imágenes rotan sobre un eje central virtual como una tragaperras premium.

gsap.to(".cylinder-wrap", {
  rotateX: -360,
  scrollTrigger: {
    trigger: ".cylinder-wrap",
    scrub: 1.5,
    start: "top 80%"
  }
});

12. Cortina Sincronizada

La imagen se fragmenta en 8 bandas verticales que se desplazan a diferentes velocidades, revelando el contenido de forma cinematográfica.

gsap.to(".curtain-img", {
  y: (i) => i * -40,
  scrollTrigger: { 
    scrub: 1, 
    trigger: ".curtain-box" 
  }
});

13. Plegado Origami (3D)

Despliegue estructural de una imagen. La foto se "abre" en tres pliegues tridimensionales a medida que entras en la sección.

gsap.from(".origami-fold", {
  rotateX: (i) => i === 1 ? 90 : -90,
  opacity: 0,
  scrollTrigger: { scrub: 0.5 }
});

14. Lente de Alta Precisión

Control de aumento por coordenadas inversas. Reacciona al ratón con inercia elástica, permitiendo una inspección premium del detalle.

// Lógica de desplazamiento inverso
cX(-relX * 1.5 + 200); 
vX(relX - 90);

15. Enjambre Cinético (Dots)

Miles de puntos (representados por una selección orbital) que se sincronizan para formar un marco magnético alrededor del contenido al acercarse.

gsap.to(".dot", {
  x: mouseX,
  y: mouseY,
  stagger: 0.01,
  ease: "back.out"
});
