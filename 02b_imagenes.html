06. Mask Reveal Color

Impacto visual inmediato. Una máscara circular (clip-path) expande un nuevo universo de color y tipografía sobre la base.

gsap.to(".mask-bg-reveal", {
  clipPath: "circle(100% at center)",
  ease: "none",
  scrollTrigger: {
    trigger: ".mask-container",
    start: "top 80%",
    end: "center center",
    scrub: true
  }
});

07. 3D Page Flip

Efecto cinemático de apertura. La imagen rota sobre su eje Y desde un ángulo de 90 grados, revelándose como la portada de un libro.

gsap.to(".flip-card", {
  rotateY: 0,
  opacity: 1,
  ease: "expo.out",
  scrollTrigger: {
    trigger: ".flip-wrap",
    start: "top 80%",
    scrub: 1
  }
});

Carrusel Continuo

Al igual que el texto, se repite la galería fotográfica clonando su interior. Ajustando al scroll para controlar la velocidad.

const tl = gsap.to(".img-ticker", {
  xPercent: -50, repeat: -1, duration: 25, ease: "none"
});

// Modificador de velocidad en tiempo real al rozar el Scroll
ScrollTrigger.create({
  onUpdate: (self) => {
    gsap.to(tl, { timeScale: self.direction * 3, overwrite: true });
  }
});

09. Lens Blur Focus

Simulación de enfoque óptico. La imagen emerge de un desenfoque profundo de 30px hacia una nitidez cristalina.

gsap.to(".blur-img", {
  filter: "blur(0px)", 
  scale: 1,
  scrollTrigger: {
    trigger: ".blur-focus-wrap",
    start: "top 80%", 
    end: "top 20%",
    scrub: true 
  }
});

10. Split Window Reveal

Apertura mecánica de visor. Dos mitades de la misma imagen se separan coordinadamente para revelar la profundidad total.

gsap.to(".left .reveal-img", { xPercent: -25 });
gsap.to(".right .reveal-img", { xPercent: 25 });
