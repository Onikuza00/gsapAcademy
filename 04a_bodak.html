02. Color Morph

Ejecución retardada (`top 35%`). Al entrar, el cuerpo y los paneles mutan al color Arena, blanqueando bordes para mimetización total. 

ScrollTrigger.create({
  trigger: "#morph-trigger",
  start: "top 35%",
  onEnter: () => {
    gsap.to("body", { backgroundColor: "var(--bg-morph)", color: "#111" });
    gsap.to(".morph-target", { borderColor: "rgba(0,0,0,0.1)", backgroundColor: "rgba(0,0,0,0.03)" });
  }
});

03. Step Stacking

Animación compactada y texto fluido. Los pasos rotan opacidades mientras las imágenes funden con un `scrub` rápido de 0.5. 

const tl = gsap.timeline({
  scrollTrigger: {
    trigger: ".prozess-scroll",
    start: "top top",
    end: "bottom bottom",
    scrub: 0.5
  }
});
tl.to(".pi-1", { opacity: 0 }).to(".pi-2", { opacity: 1 });
