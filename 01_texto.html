Cascada Reactiva (Chars)

Usando SplitText para trocear el nodo en caracteres únicos sin perder el flujo semántico nativo.

// Rompemos el texto en elementos div independientes (letras)
const split = new SplitText(".txt-cascade", { type: "chars" });

// Coreografiamos la entrada en cascada usando 'stagger'
gsap.from(split.chars, {
  y: 80,              // Empieza muy por debajo de su linea base
  rotationX: -90,     // Orientación en 3D (Z)
  opacity: 0,
  stagger: 0.05,      // Retraso de 50ms entre cada letra para la ola
  duration: 1,
  ease: "back.out(2)" // Tira un 200% y rebota hiper-elástico
});

Mask Reveal (Words)

El estándar de los premios "Site of the Day". El contenedor tiene overflow: hidden, y las palabras surgen cortadas de la nada.

// Aislamos agrupando por PALABRAS, no por letras.
const split = new SplitText(".txt-reveal", { type: "words" });

// Forzamos el empuje desde un 120% del contenedor padre (que está oculto)
gsap.from(split.words, {
  yPercent: 120,      // yPercent responde mejor que los px fijos al Responsive
  stagger: 0.05,      // Ola de fluidez extrema
  duration: 0.8,
  ease: "expo.out"    // Salida explosiva, curva limpia (sin rebotes)
});

Efecto Terminal (TextPlugin)

Reescribir el DOM mediante strings, gestionando la inserción artificial asincrónica.

// Array objetivo
const msgs = ["Frontend Developer", "GSAP Master", "UX Engineer"];

// repeat: -1 es un bucle perpetuo
const tl = gsap.timeline({ repeat: -1 });

msgs.forEach(msg => {
  tl.to(".term-target", {
      text: msg,      // textPlugin escribe char-a-char automáticamente
      duration: 1.5, ease: "none", delay: 0.5
    })
    .to(".term-target", {
      text: "",       // Retroceso de borrado
      duration: 0.5, ease: "none", delay: 2
    });
});

Matrix Decode (ScrambleTex)

El plugin premium usado en estética Cyberpunk para mezclar letras aleatorias hasta fijar la palabra.

// Aplicamos Scramble (requiere registro de Plugin previo)
gsap.to(".scramble-txt", {
  duration: 2,
  scrambleText: {
    text: "GSAP SUPREME",  // Destino final
    chars: "lowerCase",    // Caracteres falsos a usar
    revealDelay: 0.5,      // Segundos de espera antes de que las letras correctas formen la base
    tweenLength: false     // Mantiene longitud estática de las palabras si es posible
  },
  ease: "power3.inOut"
});
