01. Botón Magnético (quickTo)

Los Trackers masivos necesitan Bypasses puros al motor. Enlaza un multiplicador atenuador (* 0.4) para un imán perfecto.

// Tuberías pre-compiladas
const xTo = gsap.quickTo(".mag-btn", "x", {duration: 0.4, ease: "power3"});
const yTo = gsap.quickTo(".mag-btn", "y", {duration: 0.4, ease: "power3"});

document.querySelector(".mag-wrap").addEventListener("mousemove", e => {
  // Alimentamos coordenadas relativas atenuadas al centro del botón
  xTo((e.clientX - centerX) * 0.4);
  yTo((e.clientY - centerY) * 0.4);
});

02. Track Físico (Draggable)

Plugin rey de las interacciones táctiles en Mobile. Implementa resistencia de goma en los bordes y fricción en el deslizamiento libre.

Draggable.create(".drag-slider", {
  type: "x",
  bounds: ".drag-bounds", // Límites parentales nativos
  inertia: true,          // Fricción de lanzamiento del dedo 
  edgeResistance: 0.65    // Sensación de "tirar de una goma"
});

Alterando timeScale en tiempo real sobre una línea temporal en repetición infinita conseguimos un Ticker ininterrumpible.

const tl = gsap.to(".marquee-inner", { xPercent: -50, repeat: -1, ease: "none" });

ScrollTrigger.create({
  onUpdate: (self) => {
    // Cambiamos la dirección (+ / -) y lo aceleramos durante el scroll activamente
    gsap.to(tl, { timeScale: self.direction * 1.5, overwrite: true });
  }
});

04. Botón Líquido (Ripple)

Al situar el ratón encima, calculamos las coordenadas `offsetX/Y` y expandimos un círculo de fondo desde ese origen exacto hasta llenar el botón.

btn.addEventListener("mouseenter", (e) => {
  gsap.fromTo(fill, 
    { x: e.offsetX, y: e.offsetY, scale: 0 }, 
    { scale: 50, duration: 1.0, ease: "power3.in" }
  );
});

05. Seguidor GSAP Global

Usado en todo este módulo. Un punto duro directo a las coordenadas del MouseEvent y un círculo retardado que sigue al punto.

// Set CSS General: `cursor: none;`
const xTo = gsap.quickTo(".cursor-ring", "x", {duration: 0.15});
const yTo = gsap.quickTo(".cursor-ring", "y", {duration: 0.15});

window.addEventListener("mousemove", e => {
  gsap.set(".cursor-dot", { x: e.clientX, y: e.clientY });
  xTo(e.clientX);
  yTo(e.clientY);
});
