06. Expansiones Web (FLIP)

First, Last, Invert, Play. Capturamos el estado original del elemento, lo movemos por el DOM o cambiamos su clase, y dejamos que GSAP interpole todo mágicamente.

// 1. Capturamos estado base geométrico
const state = Flip.getState(".flip-box");

// 2. Hacemos el cambio de Layout (Añadimos clase, reseteamos estilos...)
const isFull = box.parentNode === stateB;
(isFull ? stateA : stateB).appendChild(box);

// 3. Flip interpola desde el estado del paso 1 al Layout del paso 2
Flip.from(state, {
  duration: 1,
  ease: "power3.inOut",
  absolute: true  // Para transiciones fluidas en medio del aire
});

07. Interpolación SVG (MorphSVG)

La metamorfosis vectorial. No importa si la forma base tiene 3 puntos y la de destino tiene 100, GSAP empareja los vectores y los dobla perfectamente.

gsap.to("#play", {
  duration: 1.5,
  morphSVG: "#circle", // ID del SVG destino (oculto)
  ease: "elastic.out(1, 0.4)"
});

08. Trazos Procedimentales (DrawSVG)

Revela los contornos (stroke) de rutas complejas o firmas. Maneja secretamente los stroke_dasharray y dashoffset nativos de SVG.

// De 0% a 100% como si se dibujase con boli
gsap.fromTo(".draw-path", 
  { drawSVG: "0%" }, 
  { drawSVG: "100%", duration: 2, ease: "power2.inOut" }
);

10. Tooltips Custom (Seguidor Aislado)

Escondemos los tooltips clásicos, detectamos la entrada en zonas de acción (`track-zone`), revelamos la caja y la anudamos al `clientX/Y` con un smooth puro.

const xTo = gsap.quickTo(tooltip, "x", {duration: 0.2});

zone.addEventListener("mouseenter", () => {
  gsap.to(tooltip, { opacity: 1, scale: 1 });
});

zone.addEventListener("mousemove", e => {
  // Posición absoluta del mouse menos container offset
  xTo(e.clientX - rect.left);
});
