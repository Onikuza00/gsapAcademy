01 - Fade de Opacidad

La clave de este efecto es con el SplitText, coger las chars con el SplitText y con el método from establecemos el ScrollTrigger que inicie en el contenedor del texto y que parte con una opacidad baja. 


          const efecto = new SplitText("#efecto1", { type: "chars" });
          gsap.from(efecto, {
            scrollTrigger: {
              trigger: "#demo1",
              start: "top 20%",
              end: "bottom 80%",
              scrub: 1 
            },
            opacity: 0.2,
            stagger: 0.2,
          });

Ejemplo de SplitText con fade, el texto que enciende a medida que hacemos scroll. Se establece con el from partiendo de unaa baja opacidad, un efecto muy elegante y efectivo.
