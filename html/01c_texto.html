  scrollTrigger: { trigger: ".mask-wrap", scrub: 1 }

12. 3D Stairway

Arquitectura tridimensional. Los caracteres suben un escalón invisible desde la profundidad del eje Z hasta alinearse perfectamente.

gsap.to(".s-char", {
  y: 0, z: 0, rotateX: 0, opacity: 1,
  stagger: 0.1, scrollTrigger: { trigger: ".stairway-txt", scrub: 1 }
});

13. Collision Snapping

Impacto físico controlado. Las letras vuelan desde las esquinas y colisionan en el centro con un rebote elástico pesado.

gsap.from(".c-char", {
  x: () => Math.random() * 2000 - 1000,
  y: () => Math.random() * 1000, rotate: 360
});

14. 3D Long Tiles

Retícula de datos expandida. El texto GSAP ACADEMY VIP se descompone en 14 tejas pequeñas con un volteo tridimensional sincronizado.

gsap.to(".tile", {
  rotateY: 0, opacity: 1, 
  stagger: { amount: 1.5, grid: [2, 7] },
  scrollTrigger: { trigger: ".tile-grid" }
});
