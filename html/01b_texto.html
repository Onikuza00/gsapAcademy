06. Subrayado Dibujado

Un clásico para enfatizar palabras clave. Posicionamos un bloque de color en absoluto por detrás del texto (z-index: -1) y animamos su width.

// Elemento .marker es un div absoluto debajo del texto
gsap.to(".marker", {
  width: "110%",      // Sobresale un poco para estética de rotulador
  ease: "power3.inOut",
  duration: 1
});

07. Elastic Hover (Wiggle)

Rompemos la palabra y atamos un Tween hiper-elástico de GSAP al evento mouseenter de cada carácter individual.

const split = new SplitText(".wiggle-txt", { type: "chars" });

split.chars.forEach(char => {
  char.addEventListener("mouseenter", () => {
    gsap.fromTo(char, 
      { y: -20, scale: 1.2 }, 
      { y: 0, scale: 1, ease: "elastic.out(1, 0.3)", duration: 1.5, overwrite: true }
    );
  });
});

08. Fondo Inyectado (Clip-Path)

Usando -webkit-background-clip: text, el texto se vuelve transparente y muestra la imagen de fondo. GSAP anima el posicionamiento de ese fondo infinito.

// Movemos el background-position 100% en el eje X
gsap.to(".clip-txt", {
  backgroundPosition: "100% 50%", 
  ease: "none",
  duration: 10,
  repeat: -1,         // Bucle perpetuo
  yoyo: true
});

09. Glitch Analógico (RoughEase)

Utilizamos iteraciones rápidas y el potente CustomEase o valores aleatorios en un bucle cerrado para desestabilizar la matrix.

// La mejor forma de simular Glithes rápidos es repitiendo un tween errático
gsap.to(".glitch-txt", {
  x: () => Math.random() * 20 - 10, // Saltos horizontales
  skewX: () => Math.random() * 20 - 10,
  opacity: () => Math.random(),
  duration: 0.05,
  repeat: 10,  // Repite la inestabilidad 10 veces
  onComplete: () => {
    gsap.set(".glitch-txt", { x: 0, skewX: 0, opacity: 1 });
  }
});

10. Círculos Rotatorios

Dividimos el texto, y usando pura matemática calculamos una rotación rotunda en 360 grados distribuyendo los caracteres a través de la fórmula del Seno/Coseno.

// Rotación infinita del contenedor entero una vez formado el círculo
gsap.to(".circ-wrap", {
  rotation: 360,
  duration: 10,
  ease: "none",
  repeat: -1
});
