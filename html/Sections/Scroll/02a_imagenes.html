01. Parallax Interno

Efecto de profundidad donde la imagen se desplaza a una velocidad distinta al scroll dentro de un contenedor con máscara. Al tener una altura superior (160%), permite un recorrido visual fluido y cinemático.

// Movimiento vertical y zoom progresivo
gsap.to(".img-parallax", {
  yPercent: 80,     
  scale: 1.15,      
  scrollTrigger: {
    trigger: ".img-mask",
    scrub: true
  }
});

02. Scroll Horizontal

Técnica de desplazamiento lateral que utiliza pin: true para fijar la sección mientras se traslada el contenido horizontalmente. El recorrido se calcula dinámicamente según el ancho del contenedor.

// Traslación horizontal vinculada al scroll
gsap.to(wrap, {
  x: -dist,
  scrollTrigger: {
    trigger: ".horizontal-sec",
    pin: true,      
    scrub: 1
  }
});

03. Apilamiento Sticky

Combinación de position: sticky de CSS con animaciones de escala de GSAP. Las tarjetas se apilan visualmente mientras se reduce su tamaño y opacidad al ser superpuestas por la siguiente.

// Reducción de escala y opacidad progresiva
gsap.to(card, {
  scale: 0.9, opacity: 0.4,
  scrollTrigger: {
    trigger: cards[i + 1],
    scrub: true
  }
});

04. Zoom Out Inmersivo

Efecto de retrospectiva donde la imagen comienza con una escala masiva (x3) y se asienta en su tamaño original. Crea una transición suave desde el detalle hacia el plano general.

// Retorno al tamaño original (scale: 1)
gsap.to(".zoom-img", {
  scale: 1,         
  scrollTrigger: {
    trigger: ".zoom-mask",
    scrub: 1
  }
});

05. Barrido Vectorial

Revelación mediante el uso de polígonos vectoriales (clip-path). La imagen se descubre progresivamente manipulando las coordenadas de sus vértices, permitiendo barridos limpios y geométricos.

// Animación de coordenadas de clip-path
gsap.to(".wipe-img", {
  clipPath: "polygon(0% 0%, 100% 0%, 100% 100%, 0% 100%)",
  scrollTrigger: {
    trigger: ".wipe-mask",
    scrub: 1         
  }
});
