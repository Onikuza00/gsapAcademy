Scroll Mastery

Experimenta cómo el scroll natural del ratón puede orquestar paraleajes, anclajes y falsos desplazamientos horizontales. (ScrollTrack native).

Scroll ↓
// Parallax Perfecto: Movimiento síncrono del 20% interior vs scroll global
gsap.to(".img-p", {
  yPercent: 30,     // Mueve la imagen 30% hacia abajo de su propio tamaño
  ease: "none",     // Crítico: Scroll puro sin interpolación de frenada interna
  scrollTrigger: {
    trigger: ".img-mask", 
    start: "top bottom", end: "bottom top",
    scrub: true     // Link exacto de la rueda a los píxeles
  }
});
PROFUNDIDAD
// Container Animation (El falso Scroll Horizontal)
// Bloqueamos verticalmente y transformamos hacia la izquierda (-75% porque son 4 paneles)
gsap.to(".h-wrap", {
  xPercent: -75, 
  ease: "none",
  scrollTrigger: {
    trigger: ".horiz-sec",
    pin: true,      // Bloquea el componente en el centro del viewport
    scrub: 1,       // Un segundo entero de retraso elástico ("lag") premium
    end: "+=3000"   // El tiempo que el usuario 'resbalará' verticalmente (3000px)
  }
});
