01. Máscara Cinemática

Efecto de impacto visual extremo. El texto actúa como una máscara dinámica sobre una imagen de alta resolución, escalando y ajustando su tamaño mediante ScrollTrigger para revelar texturas subyacentes. 

gsap.to(".mask-txt", {
  scale: 1, opacity: 1, 
  backgroundSize: "100%",
  scrollTrigger: { trigger: ".mask-wrap", scrub: 1 }
});

02. Revelado por Máscara

Se utiliza el desbordamiento oculto (overflow: hidden) en contenedores de línea para que las palabras aparezcan desde un área invisible. Esto crea un efecto limpio y sofisticado típico de interfaces premium. 

// División por palabras para control grupal
const split = new SplitText(".txt-reveal", { type: "words" });

// Desplazamiento vertical desde fuera de la máscara
gsap.from(words, {
  yPercent: 120,      
  stagger: 0.1,       
  duration: 1.2,
  ease: "expo.out"    
});

03. Efecto Escritura

Simulación de escritura en terminal mediante TextPlugin. Útil para elementos dinámicos como roles o estados en portfolios, permitiendo borrar y reescribir contenido de forma fluida. 

// Secuencia de mensajes con borrado automático
const tl = gsap.timeline({ repeat: -1 });
tl.to(".term-target", {
  text: "Frontend Developer",
  duration: 1.5, ease: "none"
})
.to(".term-target", {
  text: "", 
  duration: 0.5, delay: 2
});

04. Decodificación Scramble

Efecto de descifrado que utiliza caracteres aleatorios antes de revelar el texto final. Se basa en ScrambleTextPlugin para generar una estética tipo hacker o de sistema de seguridad. 

// Transformación de glyphs aleatorios a texto real
gsap.to(".scramble-txt", {
  scrambleText: {
    text: "ACCESO CONCEDIDO",
    chars: "01x/{}[]!@#",
    revealDelay: 0.3
  }
});
ENCRIPTADO

05. Apertura Blur Focus

Entrada visual que combina escala y desenfoque (filter: blur). La animación suaviza la nitidez de los caracteres mientras convergen a su tamaño original, emulando el enfoque de una lente de cámara. 

// Animación de filtro CSS y escala
gsap.from(split.chars, {
  filter: "blur(20px)", 
  opacity: 0,
  scale: 1.5,           
  stagger: 0.05,
  ease: "power2.out"
});
