01. Cascada 3D Reactiva

Efecto de cascada tridimensional donde los caracteres rotan sobre un eje profundo. Se utiliza transformOrigin con valores negativos en el eje Z para crear un arco de rotación más amplio y dinámico. 

// fragmentación por caracteres
const split = new SplitText(".txt-cascade", { type: "chars" });

// Animación con rotación en X y origen desplazado
gsap.from(split.chars, {
  y: 80,              
  rotationX: -90,     
  transformOrigin: "0% 50% -50", // Definimos un punto de giro lejano para el efecto péndulo
  opacity: 0,
  stagger: 0.05,      
  duration: 1,
  ease: "back.out(2)" 
});

03. Efecto Escritura

Simulación de escritura en terminal mediante TextPlugin. Útil para elementos dinámicos como roles o estados en portfolios, permitiendo borrar y reescribir contenido de forma fluida. 

// Secuencia de mensajes con borrado automático

04. Decodificación Scramble

Efecto de descifrado que utiliza caracteres aleatorios antes de revelar el texto final. Se basa en ScrambleTextPlugin para generar una estética tipo hacker o de sistema de seguridad. 

// Transformación de glyphs aleatorios a texto real
gsap.to(".scramble-txt", {
  scrambleText: {
    text: "ACCESO CONCEDIDO",
    chars: "01x/{}[]!@#",
    revealDelay: 0.3
  }
});

05. Apertura Blur Focus

Entrada visual que combina escala y desenfoque (filter: blur). La animación suaviza la nitidez de los caracteres mientras convergen a su tamaño original, emulando el enfoque de una lente de cámara. 

// Animación de filtro CSS y escala
gsap.from(split.chars, {
  filter: "blur(20px)", 
  opacity: 0,
  scale: 1.5,           
  stagger: 0.05,
  ease: "power2.out"
});
