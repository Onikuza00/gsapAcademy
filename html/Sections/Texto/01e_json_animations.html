21. Revelado de Caracteres

Efecto de revelado vertical segmentado por caracteres. Se utiliza un transformOrigin desplazado en el eje Z para añadir sensación de profundidad durante el giro de entrada.

// Fragmentación por caracteres para control total
const split = new SplitType('#text1', { types: 'chars' });

// Animación de entrada vertical con pivote Z profundo
gsap.from(split.chars, {
  y: 50,
  opacity: 0,
  duration: 1.2,
  stagger: 0.05,
  ease: "power4.out",
  transformOrigin: "top center -50"
});

22. Desplazamiento de Palabras

Animación basada en bloques de palabras con desplazamiento lateral coordinado. Ideal para párrafos de alto impacto donde se busca una legibilidad dinámica y una estética de interfaz fluida.

// Fragmentación por palabras (Words)
const split = new SplitType('#text2', { types: 'words' });

// Desplazamiento lateral en el eje X con escalonado (stagger)
gsap.from(split.words, {
  x: 60,
  opacity: 0,
  duration: 1.2,
  stagger: 0.04,
  ease: "power2.out"
});

Curaduría experta de experiencias digitales de alta gama mediante animación sofisticada y diseño de movimiento. Superamos los límites de las interfaces web modernas utilizando GSAP para crear interacciones fluidas que cautivan a los usuarios y elevan la identidad de marca.

23. Text Invert

Efecto de inversión cromática. El texto cambia de color o contraste dinámicamente, creando un impacto visual de alta fidelidad. Ideal para resaltar conceptos clave sobre fondos complejos o gradientes.

// Inversión de color mediante capas
gsap.to(foreground, {
  clipPath: "inset(0% 0% 0% 0%)",
  duration: 1.5,
  stagger: 0.05,
  ease: "expo.inOut"
});

24. Invert Scroll

La versión interactiva del efecto Invert. La inversión de color está vinculada directamente al scroll (Scrub), permitiendo que el usuario "descubra" el texto a medida que se desplaza por la sección.

// ScrollTrigger Scrub Inversion
gsap.to(foreground, {
  clipPath: "inset(0% 0% 0% 0%)",
  scrollTrigger: {
    trigger: "#section24",
    scrub: true,
    start: "top 80%",
    end: "bottom 20%"
  }
});
