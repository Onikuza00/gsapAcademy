25. Scale Down (Characters)

Efecto de revelado cinemático donde cada carácter escala desde 1.5x a su tamaño original mientras se desplaza verticalmente. El uso de stagger crea una onda de entrada orgánica.

// Fragmentación por caracteres
const split = new SplitType('.txt-chars', { types: 'chars' });

// Animación Scale Down (de grande a pequeño)
gsap.from(split.chars, {
  scale: 1.5,
  y: 50,
  opacity: 0,
  duration: 1.2,
  stagger: 0.05,
  ease: "power3.out",
  transformOrigin: "top center -50"
});

26. Scale Down (Words)

Variante del efecto Scale aplicada a palabras completas. Este enfoque mejora la legibilidad en bloques de texto largos y mantiene una estética de diseño editorial premium y fluida.

// Fragmentación por palabras
const split = new SplitType('.txt-words', { types: 'words' });

// Animación en bloque de palabras
gsap.from(split.words, {
  scale: 1.2,
  y: 20,
  opacity: 0,
  duration: 1.2,
  stagger: 0.04,
  ease: "power3.out"
});

27. 3D Stagger Spin

Efecto de rastro cinemático con profundidad Z y letter-spacing negativo (-0.12em). Utiliza múltiples capas para crear un efecto de "enfoque" o rastro visual mientras los caracteres giran hacia su posición.

// Triple capa para efecto de rastro
gsap.from(".txt-spin", {
  rotateX: -110,
  z: -100,
  opacity: 0,
  stagger: 0.03,
  duration: 1.5,
  ease: "power3.out",
  transformOrigin: "top center -50"
});
