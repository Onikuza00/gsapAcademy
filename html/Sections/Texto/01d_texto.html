16. Entrada Cinemática

Efecto de marca de alto impacto. Combina un espaciado entre letras (letterSpacing) masivamente negativo que se expande, junto con una transición de escala y opacidad con suavizado exponencial. 

// Expansión de caracteres comprimidos
gsap.from(".vora", { 
  duration: 1.8, 
  letterSpacing: "-40px", 
  opacity: 0, scale: 0.8, 
  ease: "expo.out" 
});
VORA

17. Dúo Editorial

Revelación masiva estilo editorial. Se utiliza un factor de escala de 1.5x que converge hacia su tamaño natural, creando una sensación de profundidad y foco inmediato. 

// Transición de escala y opacidad
gsap.fromTo(".reveal-line", 
  { opacity: 0, scale: 1.5 }, 
  { duration: 1.2, scale: 1, opacity: 1, ease: "expo.out" }
);

SOUL MATERIAL

18. Profundidad Eje X

Los caracteres rotan tridimensionalmente sobre el eje X mientras se desplazan lateralmente. Esta combinación de traslación en Z y rotación crea un efecto de "vuelo" técnico y preciso. 

// Rotación y desplazamiento en 3D
gsap.from(chars, {
  x: 80, z: -100,
  rotateX: -90,
  opacity: 0,
  stagger: 0.04,
  ease: "power4.out"
});
LOS SISTEMAS DE MOVIMIENTO KINÉTICO IMPULSAN EL FUTURO DE LAS EXPERIENCIAS INTERACTIVAS MEDIANTE LA PRECISIÓN Y FLUIDEZ.

19. Giro 3D Pro

Rotación circular completa de 360 grados sobre el eje X. Al desplazar el origen de transformación (transformOrigin) hacia el fondo en Z, el giro se percibe como una revolución orbital. 

// Revolución orbital de caracteres
gsap.from(chars, {
  rotateX: -360,
  opacity: 0,
  duration: 2,
  stagger: 0.1,
  transformOrigin: "50% 0% -50px"
});
LA EVOLUCIÓN DE LA ROTACIÓN VERTICAL EN EL ESPACIO TRIDIMENSIONAL REDEFINA NUESTRA PERCEPCIÓN DE LAS INTERFACES DINÁMICAS.

20. Manifiesto V2

Revelación secuencial de bloques de texto. Una máscara de escala progresiva se aplica a fragmentos multi-línea, guiando la atención del usuario de manera rítmica y elegante. 

// Revelación secuencial de palabras
gsap.from(words, {
  duration: 1.5,
  opacity: 0,
  y: 50,
  stagger: 0.04,
  ease: "power4.out"
});
