11. Máscara Cinemática

Efecto de impacto visual extremo. El texto actúa como una máscara dinámica sobre una imagen de alta resolución, escalando y ajustando su tamaño mediante ScrollTrigger para revelar texturas subyacentes.

gsap.to(".mask-txt", {
  scale: 1, opacity: 1, 
  backgroundSize: "100%",
  scrollTrigger: { trigger: ".mask-wrap", scrub: 1 }
});
VOID

12. Escalera 3D

Construcción arquitectónica tridimensional de texto. Los caracteres emergen desde la profundidad del eje Z y rotan de manera secuencial hasta formar una estructura perfectamente alineada.

gsap.to(".s-char", {
  y: 0, z: 0, rotateX: 0, opacity: 1,
  stagger: 0.1, 
  scrollTrigger: { trigger: ".stairway-txt", scrub: 1 }
});
PASO A PASO HACIA LA SIGUIENTE DIMENSIÓN DE ARQUITECTURAS TEXTUALES.

13. Colisión Elástica

Simulación de impacto físico. Los caracteres convergen desde posiciones aleatorias masivas y colisionan en el centro, utilizando rebotes controlados para dar una sensación de peso y materialidad.

// Convergencia desde posiciones aleatorias
gsap.from(".c-char", {
  x: () => Math.random() * 2000 - 1000,
  y: () => Math.random() * 1000, 
  rotate: 360
});
COLISIÓN

14. Retícula 3D

Descomposición tipográfica en una cuadrícula de tejas independientes. Cada elemento rota de forma sincronizada en 3D, creando un efecto de panel informativo dinámico y sofisticado.

gsap.to(".tile", {
  rotateY: 0, opacity: 1, 
  stagger: { amount: 1.5, grid: [2, 7] },
  scrollTrigger: { trigger: ".tile-grid" }
});

15. Espiral Cromática

Recorrido fluido sobre un trazado complejo en espiral. El texto fluye a través de una ruta SVG mientras experimenta una transición cromática infinita basada en el ciclo HSL.

// Movimiento sobre trazado SVG
gsap.to("#m-path", {
  attr: { startOffset: "100%" },
  scrollTrigger: { trigger: ".p-svg", scrub: 1 }
});
