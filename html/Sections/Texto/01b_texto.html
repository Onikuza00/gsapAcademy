06. Subrayado Animado

Efecto de énfasis mediante un marcador que se dibuja dinámicamente detrás del texto. Utilizamos una capa absoluta con z-index: -1 cuya anchura se expande para simular el trazo de un rotulador.

// Expansión del marcador de 0 a 110%
gsap.to(".marker", {
  width: "110%",      
  ease: "power3.inOut",
  duration: 1
});

07. Interacción Elástica

Micro-interacción aplicada a caracteres individuales. Al pasar el cursor, cada letra reacciona con un salto y una escala elástica, utilizando el suavizado elastic.out para un retorno orgánico y juguetón.

// Reacción individual por carácter al hover
split.chars.forEach(char => {
  char.addEventListener("mouseenter", () => {
    gsap.fromTo(char, 
      { y: -20, scale: 1.2 }, 
      { y: 0, scale: 1, ease: "elastic.out(1, 0.3)" }
    );
  });
});

08. Texto con Textura

Uso de background-clip: text para proyectar imágenes o gradientes dentro de la tipografía. GSAP anima la posición del fondo de manera infinita para crear un efecto de flujo constante.

// Animación perpetua del fondo de textura
gsap.to(".clip-txt", {
  backgroundPosition: "100% 50%", 
  ease: "none",
  duration: 10,
  repeat: -1,         
  yoyo: true
});

09. Glitch Analógico

Simulación de error digital mediante saltos erráticos de posición, inclinación y opacidad. Se utiliza una función que genera valores aleatorios en cada iteración para un look impredecible.

// Generación de valores aleatorios para el glitch
gsap.to(".glitch-txt", {
  x: () => Math.random() * 20 - 10, 
  skewX: () => Math.random() * 20 - 10,
  opacity: () => Math.random(),
  repeat: 10
});

10. Rotación Circular

Distribución de caracteres en una trayectoria circular perfecta. GSAP gestiona la rotación continua del contenedor, permitiendo leer el texto mientras orbita sobre su propio centro.

// Rotación infinita del eje central
gsap.to(".circ-wrap", {
  rotation: 360,
  duration: 10,
  ease: "none",
  repeat: -1
});
