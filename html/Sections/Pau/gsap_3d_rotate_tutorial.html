GSAP 3D + SplitText Tutorial

1. RotateX + Stagger (Cascada Vertical)

Variación 1

RotateX: -90° + Stagger

GSAP Animation
// PAS 1: Importar SplitText (després de GSAP) gsap.registerPlugin(SplitText); // PAS 2: Crear SplitText - divideix en línies const text = new SplitText(".mi-texto", { type: "lines", // "lines", "chars" o "words" linesClass: "line" // classe per estil }); // PAS 3: Animar amb stagger gsap.from(text.lines, { duration: 1.8, // temps per cada línia rotateX: -90, // gira sobre eix X opacity: 0, // invisible y: 30, // desplaça cap avall stagger: 0.2, // 0.2s entre cada línia ease: "power2.out" });

rotateX: -90 + stagger: 0.2: La primera línia comença, i 0.2s posteriori la segona. L'efecte és una cascada vertical cap amunt!

STAGGER: stagger: 0.2 significa que cada línia trona 0.2 segons después de l'anterior. Provar 0.1 (ràpid) o 0.3 (lent).

Com fer-ho pas a pas:

  1. 1. gsap.registerPlugin(SplitText)
  2. 2. new SplitText(".element", {type: "lines"})
  3. 3. gsap.from(text.lines, {stagger: 0.2, ...})
  4. 4. Canviar stagger per controlar ritme
Variación 2

RotateX: 90° + Stagger End

GSAP Animation
// STAGGER AVANÇAT: desde final const text = new SplitText(".mi-texto", { type: "lines" }); gsap.from(text.lines, { duration: 1.8, rotateX: 90, opacity: 0, stagger: { from: "end", amount: 0.3 } ease: "power2.out" });

stagger: {from: "end", amount: 0.3}: La darrera línia comença PRIMERA i puja cap amunt. L'amount: 0.3 és el temps total del stagger.

FROM: "END": Canvia l'ordre - ara comença des de l'última línia cap a la primera. Molt útil per a efectes inversos!

Com fer-ho pas a pas:

  1. stagger: {from: "end", amount: 0.3}
  2. "end" = des de última línia
  3. "start" = des de primera
  4. "center" = des del mig
Variación 3

RotateX: -180° + Center

GSAP Animation
// STAGGER: desde center const text = new SplitText(".mi-texto", { type: "lines" }); gsap.from(text.lines, { duration: 2.0, rotateX: -180, // voltereta opacity: 0, stagger: { from: "center", amount: 0.4 } ease: "power2.inOut" });

from: "center": La línia del mig comença primer, i les demés van seguint cap a fora. Ideal per textos de 2-3 línies!

CENTER: from: "center" funciona millor quan tens número senar de línies (1, 3, 5...).

Com fer-ho pas a pas:

  1. from: "center" = des del mig
  2. amount és temps total
  3. Provar from: "random"
  4. -180 = voltereta completa
