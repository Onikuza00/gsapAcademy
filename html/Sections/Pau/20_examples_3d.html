01

RotateX
Hacia arriba

El texto gira sobre el eje X como si se abriera una puerta horizontal desde abajo.

gsap.from(line, {
  rotateX: -90,            // Giro -90° sobre eje X
  opacity: 0,
  duration: 1,
  ease: 'power2.out'
});
02

RotateY
De los lados

El texto gira sobre el eje Y como si se abriera una puerta lateral.

gsap.from(line, {
  rotateY: -90,            // Giro -90° sobre eje Y
  opacity: 0,
  duration: 1,
  ease: 'power2.out'
});
03

RotateZ
Giro en 2D

El texto gira sobre el eje Z (el plano). Es el giro más común, como girar un papel.

gsap.from(line, {
  rotateZ: -180,            // Giro -180° sobre eje Z
  opacity: 0,
  duration: 1,
  ease: 'power2.out'
});
04

RotateX
+ RotateY

Combinación de dos ejes simultáneamente. El texto se despliega en ángulo diagonal.

gsap.from(line, {
  rotateX: -90,            // Eje X
  rotateY: 45,             // Eje Y
  opacity: 0,
  duration: 1,
  ease: 'power2.out'
});
05

RotateX
+ Y + Z

Los tres ejes girando simultáneamente. Efecto caótico y complejo.

gsap.from(line, {
  rotateX: -90,
  rotateY: 45,
  rotateZ: 30,
  opacity: 0,
  duration: 1,
  ease: 'power2.out'
});
06

Con Stagger
Línea por línea

Cada línea se anima con delay entre ellas. stagger: 0.15 = 0.15s entre líneas.

gsap.from(lines, {
  rotateX: -90,
  opacity: 0,
  duration: 1,
  stagger: 0.15,            // Delay de 0.15s entre líneas
  ease: 'power2.out'
});
07

Transform
Origin: Top

El transformOrigin define el punto de giro. 'top center' = se gira desde arriba.

gsap.from(line, {
  rotateX: -90,
  transformOrigin: 'top center',            // Gira desde arriba
  opacity: 0,
  duration: 1,
  ease: 'power2.out'
});
08

Transform
Origin: Bottom

Si el origen está abajo, la animación se ve diferente: la línea gira desde su base.

gsap.from(line, {
  rotateX: -90,
  transformOrigin: 'bottom center',            // Gira desde abajo
  opacity: 0,
  duration: 1,
  ease: 'power2.out'
});
09

Transform
Origin: Left

El origen en el lado izquierdo. Perfecto para rotateY porque gira desde la izquierda.

gsap.from(line, {
  rotateY: -90,
  transformOrigin: 'center left',            // Gira desde la izquierda
  opacity: 0,
  duration: 1,
  ease: 'power2.out'
});
10

Transform
Origin: 50% 50%

Usando porcentajes. '50% 50%' = centro exacto. Puedes usar '25% 75%', etc.

gsap.from(line, {
  rotateX: -90,
  rotateY: 45,
  transformOrigin: '50% 50%',            // Centro exacto
  opacity: 0,
  duration: 1,
  ease: 'power2.out'
});
11

Scale
+ Rotate

Combina escala y rotación. El texto se hace pequeño mientras gira.

gsap.from(line, {
  rotateX: -90,
  scale: 0.5,            // 0.5 = 50% del tamaño
  opacity: 0,
  duration: 1,
  ease: 'power2.out'
});
12

Translate
X, Y, Z

Mueve el texto en el espacio 3D mientras gira. Z lo acerca/aleja de la pantalla.

gsap.from(line, {
  rotateX: -90,
  x: -100,            // -100px a la izquierda
  y: 100,             // 100px hacia abajo
  z: 200,             // 200px hacia adelante
  opacity: 0,
  duration: 1,
  ease: 'power2.out'
});
13

Duration
Velocidad

La duration controla cuánto tarda la animación en segundos.

gsap.from(line, {
  rotateX: -90,
  duration: 0.5,            // 0.5 segundos (rápido)
  // duration: 2,            // 2 segundos (lento)
  opacity: 0,
  ease: 'power2.out'
});
14

Ease
Suavidad

El ease define cómo acelera/desacelera. 'power2.out' = rápido al inicio, lento al final.

gsap.from(line, {
  rotateX: -90,
  opacity: 0,
  duration: 1,
  ease: 'power2.out'            // Otros: power1, power3, back, elastic, bounce
});
15

Skew
Inclinación

Inclina el texto como si fuera un paralelogramo. SkewX inclina horizontal, SkewY vertical.

gsap.from(line, {
  rotateX: -90,
  skewX: 45,            // Inclina 45° horizontalmente
  opacity: 0,
  duration: 1,
  ease: 'power2.out'
});
16

Delay
Retraso

El delay espera antes de empezar la animación. Perfecta para secuencias.

gsap.from(line, {
  rotateX: -90,
  opacity: 0,
  duration: 1,
  delay: 0.5,            // Espera 0.5s antes de empezar
  ease: 'power2.out'
});
17

ScrollTrigger
Animar al scroll

Dispara la animación cuando el elemento entra en la pantalla al hacer scroll.

gsap.from(line, {
  rotateX: -90,
  opacity: 0,
  duration: 1,
  scrollTrigger: {
    trigger: line,            // Elemento que dispara
    start: 'top center'            // Cuándo empieza
  },
  ease: 'power2.out'
});
18

gsap.from()
vs gsap.to()

gsap.from() = anima DESDE estos valores. gsap.to() = anima HACIA estos valores.

// from() = comienza rotado, termina normal
gsap.from(line, { rotateX: -90, duration: 1 });

// to() = comienza normal, termina rotado
gsap.to(line, { rotateX: -90, duration: 1 });
19

Timeline
Secuencias

Crea una secuencia de animaciones que ocurren una después de otra o simultáneamente.

const tl = gsap.timeline();

tl.from(line1, { rotateX: -90, duration: 1 }, 0);            // Tiempo 0
tl.from(line2, { rotateX: -90, duration: 1 }, 0.2);            // Tiempo 0.2
tl.from(line3, { rotateX: -90, duration: 1 }, 0.4);            // Tiempo 0.4
20

Perspective &
Transform-style

El CSS de soporte: perspective en el padre y transform-style: preserve-3d en elementos.

CSS:
.container {
  perspective: 1200px;            // Distancia al plano 3D
}

.line {
  transform-style: preserve-3d;            // Mantiene transformaciones 3D
}
