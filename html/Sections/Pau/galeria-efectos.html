[01] Máscara de Texto Horizontal

GSAP SplitText

Revelado elegante de texto donde los caracteres surgen desde una línea invisible en la base de cada palabra. El movimiento es fluido y orgánico, con un ligero rebote elástico que le otorga una estética moderna y premium ideal para títulos de alto impacto.

Live Demo

Gsap Academy

VER CÓDIGO 
// 1. Configuración del contenedor (CSS)
// .demo-container { perspective: 800px; transform-style: preserve-3d; }

// 2. Dividimos el texto con SplitText
const split = new SplitText("#demo-01", { 
  type: "chars, lines", 
  mask: "lines" 
});

// 3. Animación dinámica según la dirección
gsap.from(split.chars, {
  duration: 1,
  opacity: 0,
  // Cambiamos estas propiedades según el botón:
  yPercent: mode === 'top' ? -100 : 100, // Dirección vertical
  xPercent: mode === 'left' ? -100 : 0,  // Dirección horizontal
  clipPath: 'inset(100% 0 0 0)',         // El recorte (masking)
  stagger: { 
    each: 0.1, 
    from: "center" // "start", "end", "center" o "edges"
  }
});
Pasos del Efecto
  1. Máscara Dinámica (clip-path): La clave del recorte está en la propiedad clipPath: 'inset(...)'. Al variar el porcentaje del inset, definimos desde dónde empieza a "asomar" el texto.
  2. Dirección (xPercent / yPercent): Modificando estas propiedades en el estado inicial (from), controlamos si el texto cae, sube o entra lateralmente mientras se descubre.
  3. Patrones de Escalado (stagger): Aquí es donde ocurre la magia. Usamos el objeto stagger con la propiedad from para decidir el orden de aparición:
    • "start": De izquierda a derecha.
    • "end": De derecha a izquierda.
    • "center": Desde el medio hacia los lados.
    • "edges": De los extremos hacia el centro.
  4. Flexibilidad: Un solo bloque de código puede generar decenas de variantes solo cambiando estos 3 parámetros.

[02] Levantado de Texto 3D

GSAP SplitText

Levantado elástico con rastro visual exagerado. Combinamos deformación de inclinación (skew), escalado masivo y rotación para crear una "estela" cinética sin necesidad de filtros de desenfoque, manteniendo la nitidez y el impacto.

Live Demo

Gsap Academy

VER CÓDIGO 
// 1. Estado inicial exagerado (La "estela")
gsap.set(split.chars, { 
  opacity: 0, 
  scale: 2, 
  skewX: 40, 
  rotate: 30,
  x: mode === 'left' ? "-200%" : "0%" // Dinámico
});

// 2. Animación elástica de recuperación
gsap.to(split.chars, {
  duration: 1.5,
  x: "0%", scale: 1, skewX: 0, rotate: 0, opacity: 1,
  ease: "elastic.out(1, 0.4)",
  stagger: { 
    each: 0.1, 
    from: "start" // Dinámico: "center", "end", etc.
  }
});
Pasos del Efecto
  1. Deformación de Estela: Usamos skewX: 40 y scale: 2 en el estado inicial para crear una deformación visual que simula velocidad y rastro sin usar blur.
  2. Trayectoria Dinámica: Al pulsar cada dirección, variamos el startX/Y. Esto permite que el texto "vuele" desde cualquier ángulo hacia su posición final.
  3. Rebote Elástico: El uso de elastic.out(1, 0.4) es lo que da ese efecto de "asentamiento" vibrante. El segundo parámetro (0.4) controla la frecuencia del rebote.
  4. Timing Serial: Un stagger más lento (each: 0.1) acentúa la sensación de que cada letra es independiente y arrastra su propio rastro visual.

[03] Despliegue Cinemático 3D (Ejes X/Y)

GSAP SplitText

Laboratorio interactivo de transformaciones 3D. Este efecto permite experimentar con el eje X (Persiana) y el eje Y (Lateral) mediante el uso de puntos de anclaje (transformOrigin) dinámicos y patrones de escalonado (stagger) complejos, logrando siete variantes de despliegue profesional.

Live Demo

Efectos sin
Límites
Gsap Academy v3

VER CÓDIGO 
// 1. Configuración de Ejes y Anclajes
// Persiana: rotateX: -90 | transformOrigin: "top center"
// Lateral:  rotateY: -90 | transformOrigin: "left center"
// Alterno:  rotateY alternado por línea | origin alternado

// 2. Lógica de Re-Activación
tl.to(spans, {
  duration: 1.4,
  opacity: 1,
  rotationX: 0,
  rotationY: 0,
  ease: "power3.out",
  stagger: { 
    each: 0.15, 
    from: "center" // u "edges", "end", etc.
  }
});
Pasos del Efecto
  1. Puntos de Anclaje (Origin): La clave de la variante está en el transformOrigin. Para una "persiana", el anclaje es top center; para una "puerta lateral", es left center. Sin esto, el texto rotaría sobre su propio centro, perdiendo el efecto de "despliegue".
  2. Ejes de Rotación: Usamos rotateX para movimientos verticales (arriba/abajo) y rotateY para movimientos horizontales (izquierda/derecha).
  3. Patrones de Stagger: Las variantes "Centro" y "Bordes" no cambian la rotación, sino el orden de activación de los spans mediante stagger: { from: "center" }.
  4. Preserve-3D y Perspectiva: Para que el 3D sea real, el contenedor debe tener perspective y los elementos hijos transform-style: preserve-3d, permitiendo que las letras "salgan" de la pantalla.

[04] Abanico 3D: Rotación Dual (Ejes X/Y)

GSAP

Efecto de alta complejidad que combina rotaciones simultáneas sobre los ejes X e Y. Esta doble transformación genera una apertura en abanico con gran profundidad espacial, permitiendo un revelado dinámico y sofisticado.

Live Demo

Efectos sin
Límites
Gsap Academy v3

VER CÓDIGO 
// 1. Doble Rotación (X + Y)
tl04.from(spans, {
  duration: 1.2,
  opacity: 0,
  rotationX: rotX, // Dinámico (switch mode)
  rotationY: (i) => i % 2 === 0 ? 15 : -15, // Alternancia
  transformOrigin: "center center",
  transformStyle: "preserve-3d",
  ease: "power2.out",
  stagger: { each: 0.12, from: staggerFrom }
});
Pasos del Efecto
  1. Doble Eje Dinámico: A diferencia del Efecto 03, aquí animamos rotationX y rotationY al mismo tiempo. Esto crea una trayectoria curva mucho más natural y orgánica.
  2. Alternancia de Espejo: Usamos una función en rotationY para que las palabras pares e impares giren en direcciones opuestas. Esto es lo que genera el efecto visual de "abanico" o apertura.
  3. Perspectiva y Profundidad: Al tener rotaciones en ambos ejes, la propiedad transform-style: preserve-3d se vuelve crítica para evitar que el texto se vea plano durante el movimiento.
  4. Control de Variantes: Cada una de las 7 direcciones se consigue manipulando tres parámetros: el Eje Dominante (X o Y), el Anclaje (Origin) para determinar la "bisagra" del giro, y el Punto de Inicio (Stagger) para crear patrones simétricos desde el centro o los bordes.

[05] Revelado de Distorsión Líquida

GSAP SVG Filters

Inspirado en las tendencias de diseño orgánico de agencias como Active Theory. El texto se materializa a partir de una distorsión fluida mediante filtros de turbulencia SVG, creando una transición hipnótica y vanguardista.

Live Demo

Materia
Orgánica
Liquid GSAP

VER CÓDIGO 
// 1. Animación de Filtro SVG
gsap.to("#liquid-filter feDisplacementMap", {
  attr: { scale: 0 },
  duration: 1.5,
  ease: "power2.out"
});

// 2. Animación de Turbulencia
gsap.to("#liquid-filter feTurbulence", {
  attr: { baseFrequency: 0 },
  duration: 1.2
});
Masterclass: Filtros SVG Orgánicos
  1. El Generador (feTurbulence): Crea el "ruido fractal" que sirve de mapa. baseFrequency controla la escala de ese ruido: valores bajos crean nubes/humo, valores altos crean grano/cristal.
  2. El Motor (feDisplacementMap): Mueve los píxeles del texto basándose en el ruido anterior. La propiedad scale define la fuerza de ese empuje: a mayor escala, más se fragmenta el texto.
  3. Lógica de las 7 Variantes:
    • Líquido/Humo: Frecuencias bajas (0.01-0.05) para ondas orgánicas y suaves.
    • Glitch/Cristal: Frecuencias altas (0.1-0.6) para texturas digitales y granuladas.
    • Ondas: Frecuencia asimétrica (0 en X, 0.3 en Y) para forzar el movimiento en un solo eje.
    • Zoom/Magnético: Escalas masivas (>200) para un impacto inicial explosivo.
  4. Interpolación Atómica: GSAP anima estos atributos nativos del SVG hacia cero, permitiendo que la "materia" desordenada recupere su forma original (el texto nítido) de forma fluida.

[06] Persianas Cinéticas (Shutter Slices)

GSAP Clip-Path

Una técnica arquitectónica que divide el texto en láminas horizontales. Al animar cada sección con un desfase y dirección distintos, logramos un efecto de "escaneado" o construcción por capas, ideal para marcas que buscan transmitir precisión y minimalismo.

Live Demo
Tipografía
KINETIC
Shutter GSAP
VER CÓDIGO 
// 1. Fragmentación de Láminas
// Dividimos el texto en 8 insets mediante clip-path
gsap.from(".shutter-slice", {
  x: (i) => i % 2 === 0 ? -100 : 100,
  opacity: 0,
  duration: 1.2,
  stagger: 0.1,
  ease: "power4.out"
});
Masterclass: Arquitectura de Láminas (Shutter)
  1. Fragmentación Matemática: Usamos clip-path: inset(top right bottom left) para "recortar" el texto. Calculamos dinámicamente los porcentajes en JS para que cada una de las 10 láminas sea una franja perfecta.
  2. Propiedades de Control:
    • stagger: Es el alma del efecto; crea la sensación de "barrido" o "cascada".
    • perspective: Necesaria para el modo Flip; da profundidad al eje Z para que las láminas roten en el espacio.
    • transformOrigin: Define dónde se "ancla" la lámina al rotar (ej: "top center").
  3. Configuración de Variantes:
    • Scanner/Alternate: Manipulan el eje x con lógica condicional i % 2.
    • Vertical: Cambia los parámetros del inset para cortar en el eje X en lugar del Y.
    • Flip 3D: Usa rotationX para un efecto cinético mecánico.
    • Caos: Implementa gsap.utils.random() para desvincular las láminas de un patrón fijo.

[07] Rastro Cinético (Motion Echo)

GSAP Layer Ghosting

Inspirado en la fluidez del motion graphics. El texto se desplaza dejando un rastro de capas traslúcidas que lo persiguen, fusionándose finalmente en una tipografía sólida y nítida. Una demostración de inercia y elegancia visual.

Live Demo

Rastro
CINÉTICO
Echo Motion

VER CÓDIGO 
// 1. Animación del Texto Principal
gsap.from(".text-echo.main", { x: -50, opacity: 0, duration: 1 });

// 2. Animación de los Rastros (Ecos)
// Cada eco tiene un delay incremental y menos opacidad
gsap.from(".text-echo.ghost", {
  x: -50,
  opacity: 0,
  stagger: 0.05,
  duration: 1,
  ease: "power2.out"
});
Masterclass: Persistencia y Rastro Cinético
  1. Técnica de Ghosting: Clonamos el texto original en 3 capas ("fantasmas") que se sitúan detrás de la principal. Es el método más eficiente para crear rastros de movimiento sin recurrir a Canvas.
  2. Tipografía Hollow (Contorno): El texto principal usa -webkit-text-stroke para ser transparente. Esto permite que los ecos sólidos sean visibles a través de las letras, creando una sensación de profundidad técnica.
  3. Estética Digital (Matrix): Aplicamos un verde ácido #00FF41 con un desenfoque de 1px. El secreto está en el text-shadow, que emula el resplandor de los antiguos monitores de fósforo.
  4. Coreografía de Variantes:
    • Estela/Vertical: Desfase lineal en los ejes X e Y.
    • Zoom/Vortex: Manipulación de escala y rotación con back.out.
    • Wave: Uso de skewX para simular inercia elástica.
