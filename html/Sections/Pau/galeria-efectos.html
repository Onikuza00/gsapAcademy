[01] Máscara de Texto Horizontal

GSAP SplitText

Revelado elegante de texto donde los caracteres surgen desde una línea invisible en la base de cada palabra. El movimiento es fluido y orgánico, con un ligero rebote elástico que le otorga una estética moderna y premium ideal para títulos de alto impacto.

Live Demo

Gsap Academy

VER CÓDIGO 
// 1. Configuración del contenedor (CSS)
// .demo-container { perspective: 800px; transform-style: preserve-3d; }

// 2. Dividimos el texto con SplitText
const split = new SplitText("#demo-01", { 
  type: "chars, lines", 
  mask: "lines" 
});

// 3. Animamos los caracteres desde el fondo de la máscara
gsap.from(split.chars, {
  yPercent: 100,
  stagger: 0.1,
  duration: 1,
  ease: "back.out(1.7)"
});
Pasos del Efecto
  1. Entorno 3D: Preparamos el contenedor con perspective: 800px y transform-style: preserve-3d. Esto es crucial para que el navegador gestione correctamente el espacio de renderizado.
  2. División y Máscara: Usamos type: "chars, lines" y mask: "lines". Esto crea una máscara invisible por cada línea, permitiendo que los caracteres "nazcan" desde el borde inferior de cada renglón.
  3. Posicionamiento Inicial: Con GSAP, movemos los caracteres un 100% en el eje Y, dejándolos ocultos bajo su respectiva máscara de línea.
  4. Ejecución: Aplicamos un stagger de 0.1s para un efecto fluido y un ease: back para ese toque elástico característico de los diseños de alto nivel.

[02] Levantado de Texto 3D

GSAP SplitText

Control total mediante estados iniciales y tiempos absolutos. Configuramos el punto de partida con gsap.set y disparamos dos animaciones paralelas en el segundo 0.45 de la línea de tiempo para un despliegue elástico de alta precisión.

Live Demo

Gsap Academy

VER CÓDIGO 
// 1. Definimos el estado inicial
gsap.set(split.chars, { opacity: 0, x: "750%" });

const lt = gsap.timeline();

// 2. Fase de Movimiento (Inicio absoluto: 0.45)
lt.to(split.chars, {
  duration: 1.5,
  x: "0%",
  ease: "elastic.out(1, 0.25)",
  stagger: 0.1,
}, 0.45)

// 3. Fase de Opacidad (Inicio absoluto: 0.45)
.to(split.chars, {
  duration: 0.75,
  opacity: 1,
  ease: "power2.out",
  stagger: 0.01,
}, 0.45);
Pasos del Efecto
  1. Estado Inicial (Pre-flight): Usamos gsap.set para colocar los caracteres en su posición de salida (750% de distancia) y hacerlos invisibles antes de que empiece la línea de tiempo.
  2. Timing Absoluto: En lugar de usar etiquetas relativas, fijamos el inicio de ambas fases en el segundo 0.45. Esto garantiza que el efecto siempre empiece con el mismo retraso controlado.
  3. Desacoplamiento de Staggers: El movimiento usa un stagger: 0.1 (más lento) y la opacidad un stagger: 0.01 (casi instantáneo). Esta diferencia es la que crea ese "feeling" de que la letra se materializa mientras vuela.
  4. Curva Elástica: La configuración elastic.out(1, 0.25) genera una vibración rápida y seca, muy agresiva y tecnológica.

[03] Despliegue 3D (Eje X)

GSAP SplitText

Efecto de despliegue donde las líneas de texto rotan sobre su eje horizontal (X). Los caracteres se abren desde el centro del espacio 3D, creando una transición de revelado con gran profundidad.

Live Demo

Gsap Academy

VER CÓDIGO 
// 1. División por líneas
const split = new SplitText("#demo-03", { type: "lines" });

// 2. Animación RotateX
gsap.from(split.lines, {
  duration: 1,
  rotateX: -90,
  opacity: 0,
  transformOrigin: "center center",
  stagger: 0.15,
  ease: "power2.out"
});
Pasos del Efecto
  1. División por Líneas: En este caso, animamos lines en lugar de caracteres para un efecto de bloque más sólido.
  2. Giro Horizontal: Iniciamos con rotateX: -90, lo que "pliega" la línea hacia atrás.
  3. Eje Central: Usamos transformOrigin: "center center" para que el despliegue parezca una puerta abriéndose desde el medio.
  4. Perspectiva: Vital que el contenedor tenga perspective (en este caso 1000px) para el realismo del giro.

[04] Despliegue Lateral (Eje Y)

GSAP SplitText

Rotación sobre el eje vertical (Y) con alternancia de dirección. Las líneas de texto se abren como puertas batientes, creando una transición dinámica y rítmica de gran impacto visual.

Live Demo

Gsap Academy

VER CÓDIGO 
// 1. División
const split = new SplitText("#demo-04", { type: "lines" });

// 2. Animación RotateY alternada
split.lines.forEach((line, i) => {
  gsap.from(line, {
    duration: 1,
    rotateY: i % 2 === 0 ? -90 : 90,
    opacity: 0,
    transformOrigin: "center center",
    ease: "power2.out",
    delay: i * 0.15
  });
});
Pasos del Efecto
  1. Alternancia: Usamos el índice de la línea (i % 2) para alternar el giro entre 90 y -90 grados.
  2. Puerta Vertical: La rotación sobre el eje Y crea esa sensación de "puerta" que se abre hacia el espectador.
  3. Faseado: Aplicamos un pequeño delay incremental para que las líneas no se abran todas a la vez, sino en cascada.
  4. Renderizado 3D: Al igual que en los anteriores, la propiedad preserve-3d en el contenedor es obligatoria.
