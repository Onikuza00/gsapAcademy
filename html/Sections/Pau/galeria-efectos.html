[01] Máscara de Texto Horizontal

GSAP SplitText

Revelado elegante de texto donde los caracteres surgen desde una línea invisible en la base de cada palabra. El movimiento es fluido y orgánico, con un ligero rebote elástico que le otorga una estética moderna y premium ideal para títulos de alto impacto.

Live Demo

Gsap Academy

VER CÓDIGO 
// 1. Configuración del contenedor (CSS)
// .demo-container { perspective: 800px; transform-style: preserve-3d; }

// 2. Dividimos el texto con SplitText
const split = new SplitText("#demo-01", { 
  type: "chars, lines", 
  mask: "lines" 
});

// 3. Animación dinámica según la dirección
gsap.from(split.chars, {
  duration: 1,
  opacity: 0,
  // Cambiamos estas propiedades según el botón:
  yPercent: mode === 'top' ? -100 : 100, // Dirección vertical
  xPercent: mode === 'left' ? -100 : 0,  // Dirección horizontal
  clipPath: 'inset(100% 0 0 0)',         // El recorte (masking)
  stagger: { 
    each: 0.1, 
    from: "center" // "start", "end", "center" o "edges"
  }
});
Pasos del Efecto
  1. Máscara Dinámica (clip-path): La clave del recorte está en la propiedad clipPath: 'inset(...)'. Al variar el porcentaje del inset, definimos desde dónde empieza a "asomar" el texto.
  2. Dirección (xPercent / yPercent): Modificando estas propiedades en el estado inicial (from), controlamos si el texto cae, sube o entra lateralmente mientras se descubre.
  3. Patrones de Escalado (stagger): Aquí es donde ocurre la magia. Usamos el objeto stagger con la propiedad from para decidir el orden de aparición:
    • "start": De izquierda a derecha.
    • "end": De derecha a izquierda.
    • "center": Desde el medio hacia los lados.
    • "edges": De los extremos hacia el centro.
  4. Flexibilidad: Un solo bloque de código puede generar decenas de variantes solo cambiando estos 3 parámetros.

[02] Levantado de Texto 3D

GSAP SplitText

Control total mediante estados iniciales y tiempos absolutos. Configuramos el punto de partida con gsap.set y disparamos dos animaciones paralelas en el segundo 0.45 de la línea de tiempo para un despliegue elástico de alta precisión.

Live Demo

Gsap Academy

VER CÓDIGO 
// 1. Definimos el estado inicial
gsap.set(split.chars, { opacity: 0, x: "750%" });

const lt = gsap.timeline();

// 2. Fase de Movimiento (Inicio absoluto: 0.45)
lt.to(split.chars, {
  duration: 1.5,
  x: "0%",
  ease: "elastic.out(1, 0.25)",
  stagger: 0.1,
}, 0.45)

// 3. Fase de Opacidad (Inicio absoluto: 0.45)
.to(split.chars, {
  duration: 0.75,
  opacity: 1,
  ease: "power2.out",
  stagger: 0.01,
}, 0.45);
Pasos del Efecto
  1. Estado Inicial (Pre-flight): Usamos gsap.set para colocar los caracteres en su posición de salida (750% de distancia) y hacerlos invisibles antes de que empiece la línea de tiempo.
  2. Timing Absoluto: En lugar de usar etiquetas relativas, fijamos el inicio de ambas fases en el segundo 0.45. Esto garantiza que el efecto siempre empiece con el mismo retraso controlado.
  3. Desacoplamiento de Staggers: El movimiento usa un stagger: 0.1 (más lento) y la opacidad un stagger: 0.01 (casi instantáneo). Esta diferencia es la que crea ese "feeling" de que la letra se materializa mientras vuela.
  4. Curva Elástica: La configuración elastic.out(1, 0.25) genera una vibración rápida y seca, muy agresiva y tecnológica.

[03] Despliegue 3D Alterno (Eje Y)

GSAP SplitText

Revelado 3D mediante rotación lateral alternada sobre el eje Y. Cada línea se despliega en una dirección opuesta, seguido de un revelado suave del contenido secundario (párrafos y botones) para una composición narrativa completa.

Live Demo

Efecto Lateral con
Gsap
Academy v3

VER CÓDIGO 
// 1. Estructura de Perspectiva Triple (CSS)
// .text-3d { perspective: 1200px; }
// .line { perspective: 1200px; }

// 2. Animación RotateY
lines.forEach((line, i) => {
  gsap.from(line, {
    duration: 1,
    rotateY: i % 2 === 0 ? -90 : 90,
    opacity: 0,
    transformOrigin: "center center",
    transformStyle: "preserve-3d",
    ease: "power2.out",
    delay: i * 0.15
  });
});
Pasos del Efecto
  1. Perspectiva Anidada: Para un efecto 3D realista, aplicamos perspective: 1200px tanto al contenedor padre como a cada .line individual. Esto evita deformaciones extrañas en bloques grandes.
  2. Preserve-3D: Obligatorio en todos los niveles (h2, div, span) para que el navegador no aplane la escena antes de renderizarla.
  3. Jerarquía de Contraste: Combinamos textos pequeños en mayúsculas con una palabra central masiva para guiar el foco visual durante el giro.

[04] Despliegue 3D Combinado (X + Y)

GSAP

Efecto complejo que combina rotaciones sobre los ejes X e Y simultáneamente. Esta doble transformación genera una sensación de apertura en abanico con gran profundidad, ideal para revelados de sección dinámicos.

Live Demo

Combinación de
Gsap
y Ejes 3D

VER CÓDIGO 
// 1. Doble Rotación (X + Y)
lines.forEach((line, i) => {
  gsap.from(line, {
    duration: 1.2,
    rotateX: -90,
    rotateY: i % 2 === 0 ? 45 : -45,
    opacity: 0,
    transformOrigin: "center center",
    transformStyle: "preserve-3d",
    ease: "power2.out",
    delay: i * 0.15
  });
});
Pasos del Efecto
  1. Dualidad de Ejes: Al combinar rotateX y rotateY, el elemento realiza una trayectoria curva que añade mucha naturalidad al movimiento.
  2. Timing Desfasado: El uso de delay basado en el índice asegura que la cascada sea rítmica, permitiendo que el ojo siga la formación de la estructura completa.
  3. Fidelidad 3D: Al igual que el efecto anterior, requiere una configuración de perspectiva rigurosa en todos los niveles del DOM para no perder el volumen.
