Draggable con Inercia

Usado para sliders de productos o galerías premium. No solo sigue al ratón, sino que la inercia (InertiaPlugin) simula el peso del contenido al soltar, como el iPadOS.

// Hacemos que el '.drag-slider' sea arrastrable solo en el eje X
Draggable.create(".drag-slider", {
  type: "x",
  bounds: ".drag-bounds", // Limita el movimiento a su padre
  inertia: true,          // Requiere el plugin de Inercia físico
  edgeResistance: 0.65,   // Efecto goma cuando intentas tirar más allá del límite
  onDragStart: () => console.log("Lanzado!")
});

Trackers Ultrarrápidos (quickTo)

En eventos masivos (`mousemove`), pre-compilar las tuberías del motor GSAP evita un Memory Leak atroz y clava el rendimiento.

// 1. Enganche de las tuberías directamente al motor (BYPASS de gsap.to)
const xTo = gsap.quickTo(btn, "x", {duration: 0.4, ease: "power3"});
const yTo = gsap.quickTo(btn, "y", {duration: 0.4, ease: "power3"});

// 2. En el evento del DOM que va a mil por hora...
wrap.addEventListener("mousemove", (e) => {
  // Solo alimentamos números puros a las tuberías con un amortiguador (* 0.4)
  xTo((e.clientX - centerX) * 0.4);
  yTo((e.clientY - centerY) * 0.4);
});

Marquesina Infinita Sensible

El efecto Ticker. Analiza la dirección de la rueda del ratón y enruta esa información hacia la línea de tiempo (timeline) de la marquesina invirtiendo la velocidad automáticamente.

// 1. El pase infinito. xPercent: -100 sobre un clon idéntico solapa el final con el inicio
const tl = gsap.to(".marquee-inner", {
  xPercent: -50,  // Contiene dos hijos identicos, al 50% empieza de cero exacto.
  repeat: -1, duration: 10, ease: "none"
});

// 2. Detector Maestro del Scroll (ScrollTrigger)
ScrollTrigger.create({
  start: 0, end: "max",
  onUpdate: (self) => {
    // self.direction es 1 (Hacia abajo) o -1 (Hacia arriba)
    // Invierte la escala temporal de la animación con inercia
    gsap.to(tl, { timeScale: self.direction * 1.5, overwrite: true });
  }
});
