01. Cascada Reactiva en 3D

Usando SplitText fragmentamos el nodo en letras. Aplicamos un origen de transformación profundo (`transformOrigin`) para que giren desde atrás.

// 1. Troceo por letras
const split = new SplitText(".txt-cascade", { type: "chars" });

// 2. Cascada con 'stagger' y rotación asimétrica
gsap.from(split.chars, {
  y: 80,              
  rotationX: -90,     
  transformOrigin: "0% 50% -50", // Gira sobre un eje Z lejano
  opacity: 0,
  stagger: 0.05,      // Ola de 50ms
  duration: 1,
  ease: "back.out(2)" 
});

02. Mask Reveal (Words)

Se agrupa por words. El contenedor padre línea ("reveal-line") tiene overflow: hidden. Las palabras surgen cortadas mágicamente.

// 1. Aislamos por PALABRAS
const split = new SplitText(".txt-reveal", { type: "words" });

gsap.from(split.words, {
  yPercent: 120,      // Empuje absoluto relativo a la altura de la font
  stagger: 0.04,      // Muy veloz 
  duration: 0.8,
  ease: "expo.out"    // Curva de frenada seca, sin rebotes
});

03. Efecto Terminal (TextPlugin)

Reescribimos el DOM inyectando texto caracter a caracter. Perfecto para roles que rotan en el Hero de un Portfolio.

const msgs = ["Frontend Developer", "Creative Coder"];
const tl = gsap.timeline({ repeat: -1 });

msgs.forEach(msg => {
  tl.to(".term-target", {
      text: msg,      // Escribe automáticamente
      duration: 1.5, ease: "none", delay: 0.5
    })
    .to(".term-target", {
      text: "",       // Borra hacia atrás
      duration: 0.5, ease: "none", delay: 2
    });
});

04. Decodificación (Scramble)

Sustituye la cadena final por caracteres aleatorios `lowerCase` o numéricos durante la transición.

gsap.to(".scramble-txt", {
  duration: 1.5,
  scrambleText: {
    text: "INFORMACIÓN DESBLOQUEADA",
    chars: "01x/{}[]!@#", // Los glyphs hackers
    revealDelay: 0.3,    // Arranca el texto real al poco
    tweenLength: false   // Encoge/Estira la palabra dinámicamente
  },
  ease: "none"
});

05. Apertura (Blur Focus)

Usando el filtro CSS estandar, creamos una entrada visualmente cinemática. En GSAP 3 es posible animar filter: "blur(x)".

const split = new SplitText(".blur-txt", { type: "chars" });

gsap.from(split.chars, {
  filter: "blur(20px)", // Nivel de emborronado inicial
  opacity: 0,
  scale: 1.5,           // Entran desde fuera achicándose
  stagger: 0.05,
  duration: 1.2,
  ease: "power2.out"
});
