16. Intro VORA

Efecto cinemático de marca. Combina un espaciado negativo masivo con una transición de opacidad y escala expo.

// Letras comprimidas que se expanden
gsap.from(".vora", { 
  duration: 1.8, 
  letterSpacing: "-40px", 
  opacity: 0, scale: 0.8, 
  ease: "expo.out" 
});

17. Cinematic Duo

Revelación masiva estilo editorial. Usamos un factor de escala de 1.5x que se asienta en su posición natural.

gsap.fromTo(".reveal-line", 
  { opacity: 0, scale: 1.5 }, 
  { duration: 1.2, scale: 1, opacity: 1, ease: "expo.out" }
);

18. X-Value Depth

Los caracteres rotan en un eje tridimensional mientras se desplazan lateralmente con profundidad Z.

gsap.from(chars, {
  x: 80, z: -100,
  rotateX: -90,
  opacity: 0,
  stagger: 0.04,
  ease: "power4.out"
});

19. 3D Spin Pro

Rotación completa de 360 grados sobre el eje X con un origen de transformación desplazado 50px al fondo.

gsap.from(chars, {
  rotateX: -360,
  opacity: 0,
  duration: 2,
  stagger: 0.1,
  transformOrigin: "50% 0% -50px"
});

20. Manifesto V2

Revelación secuencial masiva. Una máscara de escala progresiva aplicada a un bloque de texto multi-línea.

gsap.from(words, {
  duration: 1.5,
  opacity: 0,
  y: 50,
  stagger: 0.04,
  ease: "power4.out"
});
