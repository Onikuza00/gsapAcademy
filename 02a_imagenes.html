01. Parallax Sub-Elemento

La imagen interna (160% altura) asciende progresivamente engañando al ojo dentro de su máscara restrictiva.

gsap.to(".img-parallax", {
  yPercent: 80,     // Movimiento extremo (Parallax agresivo)
  scale: 1.15,      // Zoom inmersivo
  ease: "none",
  scrollTrigger: {
    trigger: ".img-mask",
    start: "top bottom",
    end: "bottom top",
    scrub: true
  }
});

02. Scroll Horizontal Puro

Solución al área negra: Desplazamos la caja horizontalizando el excedente real que no cabe en la vista (`wrapper.scrollWidth - wrapper.clientWidth`).

const wrap = document.querySelector(".hs-wrapper");
const dist = wrap.scrollWidth - wrap.clientWidth;

gsap.to(wrap, {
  x: -dist,
  ease: "none",
  scrollTrigger: {
    trigger: ".horizontal-sec",
    pin: true,      // Fija toda la sección en la pantalla
    scrub: 1,       // Smooth delay
    end: () => "+=" + dist
  }
});

03. CSS/GSAP Stacking

Aprovechamos que CSS aporta position: sticky sin JS, y ScrollTrigger añade la compresión o escalado (`scale: 0.9`) para la percepción de peso.

/* CSS: Escalonado de 25px */
.sc1 { background: #ff0080; top: 10%; }
.sc2 { background: #7928ca; top: calc(10% + 25px); }
.sc3 { background: #0070f3; top: calc(10% + 50px); }

// JS: Animamos escala mientras entra el siguiente
gsap.to(card, {
  scale: 0.9, opacity: 0.4,
  scrollTrigger: {
    trigger: cards[i + 1],
    scroller: ".stack-wrap",
    start: "top bottom", end: "top top",
    scrub: true
  }
});

04. Retrospectiva (Zoom-Out)

La imagen carga súper aumentada (`scale: 3`), y en cuanto arrastra pantalla se asienta sobre su tamaño natural encajando en su marco delimitador.

gsap.to(".zoom-img", {
  scale: 1,         // Reducción definitiva al tamaño original
  ease: "power2.out",
  scrollTrigger: {
    trigger: ".zoom-mask",
    start: "top 80%", 
    end: "top 20%",
    scrub: 1
  }
});

05. Enmascaramiento (Clip-Wipe)

Un barrido puro y veloz empleando polígonos vectoriales nativos del navegador clip-path: polygon(). Rendimiento estelar en aceleración gráfica.

gsap.to(".wipe-img", {
  // Animamos de 0% de anchura a 100% de anchura en sus vértices
  clipPath: "polygon(0% 0%, 100% 0%, 100% 100%, 0% 100%)",
  duration: 1.5,
  ease: "power3.inOut",
  scrollTrigger: {
    start: "top 70%",
    end: "bottom 30%",
    scrub: 1         // Reversible al scroll up
  }
});
