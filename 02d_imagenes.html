16. Parrilla Divergente

Réplica del efecto Webix. Filas de imágenes que se cruzan horizontalmente mientras la sección permanece fija, creando un flujo visual contrapuesto.

gsap.to(".row-top", { x: -250 });
gsap.to(".row-bot", { x: 250 });
// Con ScrollTrigger pinned: true
ScrollTrigger.create({
  trigger: ".webix-wrap",
  pin: true, scrub: 1
});

17. Túnel Prospectivo

Inmersión total de 360 grados. Las imágenes emergen desde la profundidad Z hacia el usuario, creando la sensación de viajar por una galería infinita.

gsap.to(".tunnel-item", {
  z: 1500,
  opacity: 0,
  stagger: { each: 0.1, repeat: -1 }
});

18. Máscara de Texto Viva

Uso de mix-blend-mode y tipografía ultra-bold. El texto actúa como una ventana gigante que se expande hasta dejar ver el contenido real.

gsap.to(".mask-overlay", {
  scale: 40,
  opacity: 0,
  scrollTrigger: { scrub: true }
});

19. Burbujas Parallax

Elementos flotantes con diferentes archivos ópticos. Responden tanto al desplazamiento vertical como al movimiento del cursor (Efecto Champ).

// Parallax vinculado a data-speed
gsap.to(bubble, {
  y: () => -innerHeight * speed,
  scrollTrigger: { scrub: true }
});

20. Zoom Out Transition

Una transición de sección a sección mediante un reescalado masivo. El contenido actual se aleja revelando la nueva capa que ya estaba allí.

gsap.to(".layer-fg", {
  scale: 0.8,
  borderRadius: "100px",
  scrollTrigger: { scrub: true }
});
