# GSAP Academy - Reglas del Workspace

Este documento detalla las normas de diseño, estructura y documentación que deben seguirse estrictamente en todo el proyecto GSAP Academy.

## 1. Consistencia Estructural
- **Orden y Numeración**: Cada nueva sección o página debe respetar el orden, diseño y composición de las anteriores.
- **Menús de Paginación**: Cada vez que se incluya una nueva página en una sección, se deben modificar los menús de paginación de las páginas anteriores para conservar la numeración y el estilo.
- **Composición de Ejemplos**: Se debe respetar el layout de dos paneles (Código/Demo), la numeración secuencial y los componentes visuales de las secciones previas.

## 2. Componentes Obligatorios
- **Footer Institucional**: Cada página DEBE incluir el footer institucional (HTML) y asegurarse de que sus estilos (CSS) estén cargados para que se visualice correctamente.
- **Botones de Reinicio**: Todos los ejemplos deben llevar un botón de reinicio del efecto siguiendo el diseño de la sección.
- **Identificadores Únicos**: Asegurar que los elementos interactivos tengan IDs descriptivos para pruebas y depuración.

## 3. Contenido Académico
- **Títulos de Efectos**: Deben ser descriptivos y tratar exactamente sobre el tipo de efecto que se muestra.
- **Descripciones**: Deben ser claras y concisas, explicando qué hace el efecto y cómo se consigue técnicamente.
- **Comentarios en el Código**: Deben explicar las funcionalidades paso a paso, especialmente las nuevas aplicaciones de GSAP, detallando el "porqué" de cada instrucción.

## 4. Estándar de Documentación
- **Idioma**: Todas las instrucciones, comentarios en el código y documentación deben estar en **castellano**.

## 5. Estética y Diseño Premium
- **Aesthetics First**: Priorizar diseños que impacten visualmente.
- **Paletas de Colores**: Evitar colores genéricos; usar paletas HSL armoniosas, modos oscuros elegantes y gradientes suaves.
- **Tipografía**: Usar tipografías modernas (Outfit, Space Grotesk, Syne) y micro-animaciones para mejorar la interactividad.
